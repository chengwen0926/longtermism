# 桌面版改造与验证记录

日期：2026-10-26。

## 本轮实现决定

从单文件 HTML 原型改为 Swift / AppKit + WKWebView 桌面应用。采用与讨论中相同的“原生窗口承载网页界面”方式；本机已有 Swift 工具链，因此不引入 Go / Wails。业务界面保持可在浏览器预览，系统窗口、菜单和文件读写由 Swift 承担。

主要变化：拆分界面代码，接入持久化存储，保存时展示真实状态，开发模式支持界面自动刷新与 Swift 自动编译重启。原型中的递增 ID 改为 UUID，避免重开应用后新记录与既有记录重复。

当前日期采用设备本地日期，窗口跨日后会更新；表单编辑期间暂缓刷新。开发版、独立版与浏览器预览各自使用独立存储。

## 窗口边缘缩放排查（2026-10-26）

用户报告窗口边缘完全无法调整尺寸。原代码已有 `.resizable`，因此并非未启用缩放。为排除全尺寸网页对原生边缘命中的干扰，移除 `.fullSizeContentView`，恢复标准标题栏；以原生容器承载 WebView，保留 4 pt 边缘命中区域；内容最小尺寸设为 640 × 480 pt。

构建通过，开发窗口已加载新版本。自动化工具的原生拖拽操作返回 `noWindowsAvailable`，未完成自动验证；用户随后实际拖拽验证并确认“现在可以了”。标准标题栏与边缘区域调整已解决用户遇到的问题，具体底层触发原因未进一步隔离。
