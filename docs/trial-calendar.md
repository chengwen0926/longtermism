# 考察日历

2026-10-26：新增侧栏「考察日历」，以月度时间轴显示所有考察项目的周期。

## 产品约定

- 每行对应一个考察周期；左侧显示完整起止日期、总天数、状态和全周期行动完成数。右侧按当月日期绘制时间条。
- 跨月周期在月边界裁切，用箭头与虚线边界表示延续；原始日期不变。点击项目或时间条打开现有详情，可返回原月份与筛选。
- 上月、下月、本月及月份输入用于浏览；支持全部周期、未归档、已回顾筛选。状态仍以今天为准。
- 月度统计仅覆盖当前筛选：涉及的周期数量、覆盖天数（按日期去重）、每日同时覆盖的周期数及其峰值。继续/调整后生成的新周期单独占一行。
- 考察起止日均计入。这是计划区间统计，不代表实际投入时间，也不构成日程冲突判定。
- 保留现有本机保存方式，不新增数据字段或迁移；日历直接读取共享计划与行动。月份和筛选为临时界面状态。

## 验证

- 日期模型测试覆盖跨月裁切、单日区间、首尾相接重叠、已归档周期、整月覆盖、空月份、闰年二月及跨年导航。
- 浏览器预览实际验证：月度时间条、跨月延续、打开详情及返回、完成行动后同步为 4/6、回顾生成下一周期、已回顾筛选、跳转到 2027 年 1 月及空状态。
- 测试使用独立预览端口与浏览器数据，不修改桌面版用户记录。
- 760×600 窗口检查通过：页面宽度保持 760px，时间轴在自身区域横向滚动；桌面宽屏截图见 `trial-calendar-preview.jpg`。
- JavaScript 语法检查、全部 10 项现有及新增测试通过；macOS 应用构建与签名校验通过，打包的日历、主界面和样式与源文件一致。
