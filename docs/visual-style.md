# 组件设计对照（Magpie 参考）

核对日期：2026-10-26。

参考 [Magpie 的公开组件样式](https://github.com/yetone/magpie/blob/main/internal/gui/assets/app.css)，本轮按实际 CSS 定义逐项核对；这是对当前 longtermism 组件的适配，不是对 Magpie 全产品功能的复刻。

## 组件对应与调整

| longtermism 组件 | Magpie 参考 | 本轮调整 |
| --- | --- | --- |
| 主题与表面 | `:root` / 深色变量 | 保留中性色背景；补全强调色前景、弱边框、分段选中层与控件阴影变量 |
| 侧栏导航 | `.sidebar` / `#nav button` | 30px 导航行、紧凑图标间距、选中层阴影；中间区域独立滚动 |
| 计划快捷入口 | 侧栏选中与状态语义 | 当前计划独立高亮；待回顾显示琥珀色圆点；长标题悬停可读；分组改为“未归档的考察” |
| 面包屑 | `.crumb` | 页面图标随视图变化，详情显示计划名称，长名称省略避免挤压保存状态 |
| 主次按钮 | `.text.action` / `.text.primary` / `.text.danger` | 主按钮蓝紫色，次按钮中性表面，轻量按钮无边框，危险操作悬停红色；统一按下与焦点反馈 |
| 分段筛选 | `.seg` / 分段变量 | 独立轨道与选中层，浅色白色选中块、深色提亮；每项显示数量并保留切换后的焦点 |
| 卡片与列表 | `.list` / `.row` / `.tile` | 10px 卡片圆角、16px 内容间距、紧凑标题；任务键盘聚焦与悬停使用同一底色 |
| 标签与状态 | `.badge` / 语义颜色变量 | 示例标签使用柔和底色，计划状态加入浅色底；重要性仍由文字、编号与颜色共同表达 |
| 输入框与下拉框 | `.editor input` / 弹出控件语言 | 统一边框、30px 最小高度、蓝紫柔和焦点环；下拉箭头统一，保留原生选择与日期输入行为 |
| 单选与复选 | `input[type="checkbox"]` | 统一 14px 复选外观，完成行动与表单选中使用相同强调色；补充禁用、只读与键盘焦点表现 |
| 弹窗 | `.modal .editor.framed` | 固定标题与底部按钮，只有字段区滚动；14px 圆角、模糊遮罩、打开时聚焦首个输入项 |
| 空状态 | `.empty-state` | 筛选无结果时显示对应说明和创建入口，避免只剩一张新建占位卡 |
| 进度与反馈 | 共享颜色和表面 | 进度增加可读名称与数值；Toast 改用卡片表面；保留保存、错误、重试反馈 |

此前文档所述的“主按钮使用高对比黑白”与本轮核对到的 Magpie `.text.primary` 定义不一致，现以蓝紫强调色为准。

## longtermism 的适配决定

- 保留四象限、计划详情和回顾的业务结构；任务分类与持久化格式不变。
- 中文表单仍采用标签在上的布局，并使用比 Magpie 27px 文本框稍高的 30px 控件。
- 在 1000px 以下把详情辅助面板移到正文下方，避免桌面最小窗口挤压任务列表；窄屏继续使用单列布局。
- 分组单选采用 `fieldset` / `legend`；视图重绘后恢复原控件焦点，控件消失时回到页面标题。
- 浏览器没有实现原生菜单快捷键，因此只在桌面版显示 `⌘N` 提示。

## 验证

- JavaScript 语法检查和现有 5 项模型/存储测试通过。
- macOS 应用构建通过，签名校验与 Info.plist 校验通过。
- 浏览器实际操作验证：新增行动、切换象限单选、提交、显示已完成后保留焦点、计划筛选及空状态、创建计划、详情与回顾选项切换。
- 1220×880 深浅色页面、760×600 回顾弹窗及 390×844 长标题详情检查通过，无页面横向溢出。760×600 弹窗字段区可滚动，标题和底部操作仍在可视范围。
- 浅色通过临时预览服务启用同一份 CSS 的浅色规则验证，没有修改系统外观。该服务的数据与桌面版隔离。
- 真实 macOS 开发窗口已显示新的矩阵和组件样式。本轮没有声称完成 VoiceOver 全流程或跨操作系统测试。

## 最终复核补充
